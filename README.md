# SJP Consulting website — "The Quiet Broadsheet"

The rebuilt sjpconsulting.com. A single static page designed as an instance of what the practice sells: a document that survives examination. Warm paper, one serif (Newsreader) plus one mono (IBM Plex Mono), hairline rules, numbered sections, the career as a ledger table, and everything quantitative set as a captioned Exhibit. Exhibit 1 (the hero fan chart) and Exhibit 2 (the live Monte Carlo NPV model) are generated by the same seeded engine, so the static charts and the default live run reproduce each other exactly.

## Layout

```
index.html                 the site, built and deployable as-is
build/
  template.html            page source with placeholders
  exhibits.js              seeded Monte Carlo engine + SVG chart generators
                           (runs in Node at build time and in the browser live)
  ui.js                    theme toggle + live model wiring
  build.js                 injects baked SVGs, results and scripts -> ../index.html
.github/workflows/publish.yml   rebuilds and deploys to GitHub Pages on push
```

To edit copy or styling: edit `build/template.html`, then `cd build && node build.js`. Never edit `index.html` directly; it is generated.

## Before launch

1. Fill the placeholders in `build/template.html`: `REPLACE_WITH_EMAIL`, `REPLACE_WITH_PHONE`, `REPLACE_WITH_ABN`. Rebuild.
2. Confirm every ledger row's wording. Nothing ships unverified; a Period column can be added once dates are confirmed (`<!-- PERIOD COLUMN -->` marker in the template).
3. Optional but recommended: self-host the two fonts. Download Newsreader and IBM Plex Mono as woff2 (both are OFL-licensed), drop them in `fonts/`, replace the Google Fonts `<link>` with `@font-face` rules. This removes the only third-party request the page makes.

## Deploy

GitHub Pages: push to a repo, enable Pages with "GitHub Actions" as the source; the included workflow rebuilds and deploys on every push. Add the custom domain in Pages settings.

Cloudflare Pages: connect the repo, build command `cd build && node build.js && cp index.html ..`, output directory `.`.

Domain and email cutover: see the migration plan (SJP Strategy project). Short version: move DNS to Cloudflare first (re-creating the Google Workspace MX/SPF records), verify mail, then point the domain at the new host, then cancel Weebly.

## Adding analytics pages later

The homepage is deliberately hand-set; keep it that way. For tool and analysis pages, render Quarto documents into a subfolder (e.g. `quarto render tools/ --output-dir ../tools`) and link them from the Elsewhere or Model sections. Quarto pages can reuse the same palette tokens; Shinylive apps embed directly in Quarto and run in the browser, which keeps the "client-side, no data leaves the page" property.

## Design tokens

Light: bg `#F6F2E9`, surface `#FCFAF4`, ink `#1D1B16`, muted `#625D50`, border `#D9D2C0`, accent (oxblood) `#7E2D1E`, chart series 2 `#3D5A73`.
Dark: bg `#1B1913`, surface `#232019`, ink `#ECE6D6`, muted `#A79F8B`, border `#3B372C`, accent `#D89B84`, series 2 `#5E97C4`.
Rules: negatives render in the accent sitewide (red-ink convention); series 2 appears only on the CDF; every figure outside prose is mono with tabular numerals; no border-radius, no shadows, no icons; all content visible without JavaScript.

## Engine notes

Correlated revenue and cost shocks via 2×2 Cholesky over Box-Muller normals, shock multipliers floored at zero, growth applied as (1+g)^(t−1), end-of-year discounting, Mulberry32 PRNG seeded at 42. 10,000 trials rerun in ~70ms. Determinism is exact on V8 (Chrome, Edge, Node); other engines agree to display precision.
